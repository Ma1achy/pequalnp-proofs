# One Hamiltonian-tour generator separates two exact elimination procedures

For every m≥2 there is an ordinary CNF with O(m³) variables and O(m³) clauses of width at most four whose projection onto the m(m−1) labelled directed edge bits is exactly the edge sets of directed Hamiltonian cycles. The circuit has no asserted edge output. On this same CNF, in reverse topological order the forbidden-flat solver with Gaussian normalization, deduplication, containment deletion and parallel merging never creates a nonempty pair candidate. Its number of stored flats never exceeds the initial clause count. Its complete SAT run takes polynomial bit time. The full syndrome-table procedure has some layer with m^{Ω(m)} entries in every order, by the separately established Hamiltonian-tour encoding theorem and the cited rectangle bound there. [Syndrome lower bound and hypotheses](tour_encoding.md) · [Independent audit](tour_review.md)

## Total circuit with every tour in its image

Pin vertex 0 as the first vertex in the cyclic listing. Start the remaining m−1 positions in the order 1,…,m−1. For i=2,…,m−1 append the following stage to a fixed swap schedule. Treat vertex i as the new rightmost member of the first i positions and visit adjacent boundaries from positions (i−1,i) down through (1,2). Put a separate unconstrained Boolean control on every such swap. Every setting of the (m−1)(m−2)/2 controls yields a permutation. For an arbitrary goal permutation, induct on i; starting with its relative order on 1,…,i−1, turn on just the initial segment of swaps needed to insert i at its position among 1,…,i. The resulting final order is the goal permutation. Multiple controls may give the same permutation.

Represent each slot by a one-hot vector of m−1 wires, initially using fixed zero and one gates. A controlled swap of two slots uses a multiplexer in each direction for every coordinate. For distinct u,v away from 0 compute the OR, over consecutive slots, of “[the first contains u] AND [the second contains v]”. An edge leaving 0 uses the corresponding first-slot bit and an edge returning to 0 uses the last-slot bit. Make one final fresh copy sink per edge after all these internal wires have been constructed. There are no loops in the visible coordinates. All muxes, ANDs, ORs, copies and constants are total Boolean functions. Trivial constant operands are simplified when building the circuit.

For a gate g of a≤3 distinct preceding inputs, and each of the 2ᵃ possible input tuples, emit the ordinary clause that forbids that tuple with the incorrect value of g. This also gives the single defining clause for a constant. A fixed control assignment has one extension to all gates, and the visible edges of that extension are exactly the directed tour around the generated permutation. Anchoring at 0 lists every directed tour. It follows that existential projection of **all** private gate and control variables gives exactly the desired relation on distinct fresh visible bits.

There are O(m²) swaps and at most 2(m−1) muxes per swap. Computing all edge indicators requires O(m³) binary gates and O(m²) final copies. Every gate has at most eight clauses. With binary identifiers, a direct sparse input uses O(m³ log(m+1)) bits. The experiment's fixed-width dense row format uses O(m⁶) bits. Emitting the dense rows by shifts and elementary scans takes O(m⁶ polylog(m+1)) bit operations. All coefficients have one bit.

## Reverse order for the generic flat solver

Give smaller variable IDs to controls than gates, and each gate an ID larger than all its inputs. A nonempty forbidden flat of a single gate is a subset of its *incorrect-output graph* g=1+f(inputs), unrestricted on later variables. Its coefficient space must contain some row with nonzero coefficient of g; otherwise flipping g at any point would remain in the flat, contradicting containment in that graph. Its highest supported variable is therefore exactly g.

RREF and deduplication preserve that property. Containment deletion only removes flats. Parallel coset merging replaces two flats with the same linear row space by their affine union in the binary field. Parallel flats have the same highest supported variable and hence belong to the same gate. Their union is still contained in the same incorrect-output graph, so it still has g as its highest supported variable. Thus these facts survive every initial simplification. Even during merging no gate has more flats than its original at most eight clauses; widths start at most four and merging can only decrease them.

Eliminate in decreasing variable ID. At the step for g, all remaining flats in which g occurs are attributed to g. Flats of earlier gates are cylinders with respect to g. Given values of the remaining variables, f(inputs) is a permitted value in every incident flat simultaneously, since none can forbid a correct gate value. Two incident graph flats can never prescribe opposite forbidden values on overlapping domains, so all pair candidates reduce to inconsistent systems. The result is the subset of preceding cylinders. Their antichain and parallel-merge normalization were complete before deleting the incident group. They remain so as a subset with no new direction repetitions. This reasoning continues down to the controls, which have no defining factors. The empty final cover returns SAT. The proof uses the actual pair algorithm and its simplifications; an existential gate wire is never left unresolved.

With C raw clauses and n total variables use T=1+C+n. There are at most eight incident graph flats and 28 pairs at each gate. A pair has at most 7 raw rows of n+1 bits, so exact consistency checks cost polynomial bit time. To include the solver's general-purpose simplifier conservatively, an antichain/grouping pass on at most C flats of at most four n-bit rows uses O(C²(n+1)²(log₂(T+1))²) bit operations. This allows worst-case linear scanning on dictionary collisions, comparing and XORing full-width rows, sorting, the widths of counters/indices and explicit copies. At initialization each merge reduces cardinality, so at most C+1 such passes are needed; subsequent projection of an already normalized subset needs one pass per variable. RREF on a raw input, on a merged flat, or on a pair uses at most 7 rows throughout. Even the loose **O(T⁷) bit time and O(T⁴) bits of space** account for initialization, every projection, the temporary pairs, and the final decision. T is polynomial in the original explicit encoding length and m. The full syndrome table lower bound refers to the rank of the original factors touched by an order, which can be large despite all the pair conflicts in this particular reverse elimination being empty.

The family is always satisfiable and represents the **set of all tours of the complete loopless digraph**. Imposing allowed-edge restrictions to ask whether a supplied graph contains a tour adds factors on the output sinks and changes the reverse-order argument. No general graph Hamiltonicity or unrestricted SAT decision algorithm follows.

## Reproduction

Run `python3 cycle2/generator_flat.py` from the research directory. It tests the CNF of each gate independently against a fixed truth table, verifies that every edge is a fresh sink, checks all control settings against an independent list-swapping implementation through m=6, and constructs controls explicitly for every anchored permutation. It tests 64 seeded random controls and 64 seeded target permutations for each of m=7,8, using seed 49271. For m=2,3 it also projects all helpers while retaining the edges and compares all 4 and 64 visible assignments to the true tour relation.
