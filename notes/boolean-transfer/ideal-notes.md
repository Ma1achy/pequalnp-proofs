# Boolean equivalence and the two formal projections

All polynomial statements use Mathlib's formal multivariate polynomial ring. For a commutative ring \(R\), the ideal generated by every \(X_i^2-X_i\) is contained in the kernel of evaluation at each Boolean point. For finitely many variables over an integral domain, equality of cube functions is exactly equality modulo this ideal. The converse specializes Mathlib's combinatorial Nullstellensatz to the grid \(\{0,1\}\) in each variable. Every congruence class has exactly one representative of degree at most one in each variable. The existence proof replaces each monomial by the product of the variables in its support. The proof of uniqueness uses the grid root bound. Processing a formal monomial expansion gives no polynomial size bound in the size of a DAG computing it. [BooleanIdeal.lean](BooleanIdeal.lean)

For \(Q=(X_i^2-X_i)\prod_{a\ne i}X_a\) the canonical multilinear representative is zero. Yet on singleton blocks the paper's full block-linear projection is \(-\prod_aX_a\), nonzero in every nontrivial commutative ring. At any cutoff \(d\ge1\), the sum of the degree-\(0,\dots,d\) homogeneous components of \(X_i^{d+1}-X_i\) is \(-X_i\). At the actual word code of the nil tree with two places, the first coordinate for the letter false is one, so the original polynomial evaluates to zero while the truncated sum evaluates to \(-1\). The two differ over \(\mathbb F_2\) as well. A uniform obstruction works for **every** polynomial \(P\), over every commutative ring. Simultaneously substitute \(X_i\mapsto X_i^e\) with \(e\ge1\). The resulting formal polynomial has the same Boolean values. With \(e=2\) its full block-linear projection vanishes whenever at least one block is present. Every candidate monomial has some coefficient index equal to one, while dilation makes every exponent even. With \(e=d+1\), the entire low-degree sum is the constant \(P(0)\), since all total degrees are multiples of \(e\). A DAG translation can share powers of each input across all original uses. The checked straight-line construction interleaves all input dilations by powers of two for each original gate. For exponent \(2^t\) it uses at most \((t+1)S\) gates for an original \(S\)-gate circuit. Binary powering for a general exponent costs \(O(\log(e+1))\) extra multiplications per distinct occurring input, at most one squaring per input for \(e=2\). This proves failure of these specific projection operations to descend to Boolean functions. It gives no lower bound on the size of the best representative. The separate characteristic-two repeated-output-squaring result also allows arbitrary subsequent polynomial substitutions. [BooleanIdeal.lean](BooleanIdeal.lean) · [Frobenius.lean](Frobenius.lean)
