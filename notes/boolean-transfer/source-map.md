# Where the Boolean transfer fails in the VP ≠ VNP source

The inspected revision of Anthropic’s `formal-math` is `11b6c7e3c927df2658f513b6b68ea7f8929c62c5`. Printed §2.5, p. 10, identifies two uses of the formal polynomial inside an arithmetic circuit. Appendix Q, Table 3, maps E.4 to `lem_balanced` and K.2 to `lem_lowdeg`. The latter lemma works for a polynomial of *any* degree. The gap for Boolean circuits arises when K.3 identifies its truncated answer with the desired function. The examples below test that specific identification. They leave both source lemmas intact. [Paper, §§2.5, E, K, Q](https://github.com/anthropics/formal-math/blob/11b6c7e3c927df2658f513b6b68ea7f8929c62c5/vp-vnp/paper.pdf)

## Statements and model

| Item | What the pinned declarations say |
| --- | --- |
| Arithmetic computation | A list of at most the specified number of gates contains the output **as a formal polynomial**. A gate is a variable, a field or ring constant, or the sum or product of two earlier gates. Inputs count, fan-out is free and operands may coincide. There is no intermediate formal-degree restriction. [Statement.lean, lines 20–27](https://github.com/anthropics/formal-math/blob/11b6c7e3c927df2658f513b6b68ea7f8929c62c5/vp-vnp/Statement.lean#L20-L27) |
| Main bound | There is an absolute positive constant c. For each characteristic there is a size threshold above which HC needs more than m raised to c(log₂ m)^(1/3) gates over every field of that characteristic. The same holds for the permanent outside characteristic two. Both targets are explicitly defined cycle/permutation sums. [Statement.lean, lines 29–46](https://github.com/anthropics/formal-math/blob/11b6c7e3c927df2658f513b6b68ea7f8929c62c5/vp-vnp/Statement.lean#L29-L46) |
| Approximate computation | Each monomial coefficient is a Laurent series in ε. Its negative ε-coefficients must vanish, and its ε⁰-coefficient must equal the target monomial’s coefficient. This condition retains the entire formal target. [Statement.lean, lines 50–60](https://github.com/anthropics/formal-math/blob/11b6c7e3c927df2658f513b6b68ea7f8929c62c5/vp-vnp/Statement.lean#L50-L60) |
| Nonuniform families | VP bounds the variable count, formal *output* degree, and circuit size by nᵃ+a for one fixed a. Each n has its own circuit and constants. VNP uses a formal polynomial identity, summing a VP family over Boolean witness vectors. The polynomial bound on the verifier’s variables bounds the witness length. The value of a sum can be zero when witnesses exist. [Statement.lean, lines 64–96](https://github.com/anthropics/formal-math/blob/11b6c7e3c927df2658f513b6b68ea7f8929c62c5/vp-vnp/Statement.lean#L64-L96) |

On a directed graph with Boolean adjacency entries, HC evaluates in the base field to the number of directed Hamiltonian cycles. For the complete loopless directed triangle there are two, one per orientation. Over ℤ/2 the value is zero while Hamiltonicity is true. The paper’s phrase “a Boolean circuit for HC” in §2.5 concerns the Boolean-valued *parity* function given by the polynomial over ℤ/2. A Boolean circuit deciding existence solves a different problem. A superpolynomial unrestricted circuit lower bound for an NP language would establish NP ⊄ P/poly and hence P ≠ NP. A bound for a single prescribed arithmetic representative supplies neither step. Aaronson explicitly distinguishes formal computation over finite fields from computation of the induced function, and explains the nonuniform and counting aspects of Valiant’s conjecture in his historical survey. [HC definition](https://github.com/anthropics/formal-math/blob/11b6c7e3c927df2658f513b6b68ea7f8929c62c5/vp-vnp/Statement.lean#L33-L36) · [Aaronson, *P =? NP*, §§5.2 and 6.5, pp. 32–33, 72–75](https://www.scottaaronson.com/papers/pnp.pdf)

## Two source operations

**E.4, flat case.** Variables form k equal-size blocks indexed by a finite type T, with k≥2. `linearPart` selects the ordinary monomials consisting of precisely one variable to exponent one from each block. From an L-gate circuit for P, `lem_balanced` represents that selected part as a sum over balanced subsets S, k ≤ 3|S| ≤ 2k, with L products per subset, each factoring across S and its complement. The coefficient version and its application appear at lines 264–269 and 345–351. On the Boolean cube, separate exponents can collapse onto the same monomial, so selection on a representative can change. §2.5 gives the example (x₁²−x₁)x₂⋯xₖ. [Definition](https://github.com/anthropics/formal-math/blob/11b6c7e3c927df2658f513b6b68ea7f8929c62c5/vp-vnp/Paper/Flat.lean#L185-L187) · [Lemma](https://github.com/anthropics/formal-math/blob/11b6c7e3c927df2658f513b6b68ea7f8929c62c5/vp-vnp/Paper/Flat.lean#L233-L237) · [Coefficient application](https://github.com/anthropics/formal-math/blob/11b6c7e3c927df2658f513b6b68ea7f8929c62c5/vp-vnp/Paper/Flat.lean#L345-L351)

**K.2, contracting case.** Write T_d(P) for the sum of the *formal* homogeneous components of degrees 0 through d. If a polynomial over a commutative ring has an S-gate circuit, with S ≤ 2ᴹ and N ≤ 2ᵐ, K.2 supplies a weighted program D with a trie K of constants. On every short tree word z, its value is T_d(P)(code(z)). The variables are N positions times the two symbols and end mark. The code has a one for each letter in its position and a one in the end-mark position. All runs halt on the short inputs. The explicit cost bound applies to accepting runs. Appendix Q pp. 69–70 corrects that possible reading of the printed lemma. The quantity `val` aggregates weighted runs. It supplies no deterministic Boolean running-time bound. [K.2, including all resource bounds](https://github.com/anthropics/formal-math/blob/11b6c7e3c927df2658f513b6b68ea7f8929c62c5/vp-vnp/Paper/LowDeg.lean#L38-L52) · [Word encoding](https://github.com/anthropics/formal-math/blob/11b6c7e3c927df2658f513b6b68ea7f8929c62c5/vp-vnp/Nc/Acc/Prog.lean#L159-L161)

The proof restricts P to the *formal* line through the origin and u. Algebraically, [tⁱ]P(tu) equals the evaluated i-th homogeneous component of P. Product gates use ordinary coefficient convolution. This is why x and x² contribute in different degrees even if u=1. Treating t²=t here would directly change the coefficient identity. [Line-coefficient lemma](https://github.com/anthropics/formal-math/blob/11b6c7e3c927df2658f513b6b68ea7f8929c62c5/vp-vnp/Paper/LowDeg.lean#L19-L34) · [Gate recursion](https://github.com/anthropics/formal-math/blob/11b6c7e3c927df2658f513b6b68ea7f8929c62c5/vp-vnp/Paper/LowDegChains.lean#L19-L27)

## Exact use in K.3

1. For a formally grid-complete family G, `lem_circuit_universal` supplies an affine substitution Mat, the formal degree bound deg(G_m(Mat)) ≤ N = v^(H−32)+1, and the **full** evaluation identity with the universal value pv(θ,z) on the short plain instances. These are separate conclusions. The proof uses the properties it needs of Φ. Appendix Q distinguishes them from an identity with the printed sum over words. §2.5 describes the Boolean behavior of the substitutions marked P. The formal HC projection corollary promises affine entries and an exact substituted polynomial identity. Over ℤ/2 every such entry maps Boolean points to Boolean points. [Universal substitution](https://github.com/anthropics/formal-math/blob/11b6c7e3c927df2658f513b6b68ea7f8929c62c5/vp-vnp/Paper/Circuit.lean#L63-L75) · [HC projection](https://github.com/anthropics/formal-math/blob/11b6c7e3c927df2658f513b6b68ea7f8929c62c5/vp-vnp/Paper/HcGrid.lean#L75-L81)
2. `lem_circuit_program` specializes K.2 with d=N. Its theorem still returns the truncated answer for any circuit output. The proof of `lem_circuit` takes the formal degree fact `hdeg` at line 305, feeds the projected circuit to the program at lines 310–311, then uses `hdeg` at lines 317–321. Every omitted formal homogeneous component vanishes. Only then can it replace the truncated value by the full value and apply the universal evaluation identity. [Specialization](https://github.com/anthropics/formal-math/blob/11b6c7e3c927df2658f513b6b68ea7f8929c62c5/vp-vnp/Paper/Circuit.lean#L133-L146) · [Proof of K.3](https://github.com/anthropics/formal-math/blob/11b6c7e3c927df2658f513b6b68ea7f8929c62c5/vp-vnp/Paper/Circuit.lean#L294-L321)
3. K.3 turns a small formal circuit into an accelerator. In a contracting field `contracting_complete` contradicts the independently established absence of that accelerator. At the main exact theorem, the proof branches on the flat/contracting alternative. The approximate analogue works because truncating Φ+εg preserves Φ at ε⁰ coefficientwise when deg Φ ≤ N. A Boolean-ideal perturbation has no analogous formal coefficient guarantee. ## Two algebraic tests at the actual cutoff

**One end-mark variable.** Fix N≥1 and a short word w, and take x to be its end-mark variable. For any nontrivial commutative ring, Q=x^(N+1)−x vanishes on the whole Boolean cube, yet T_N(Q)=−x takes the nonzero value −1 on code(w). Repeated squaring and binary powering give an O(log(N+1))-gate circuit. Adding Q to any proposed projected polynomial preserves every coded value and changes its K.2 answer there. This disproves representative-independence of the *value at a genuine code*, even at K.3’s chosen cutoff d=N. [Code used in K.2](https://github.com/anthropics/formal-math/blob/11b6c7e3c927df2658f513b6b68ea7f8929c62c5/vp-vnp/Nc/Acc/Prog.lean#L159-L161)

**Perturb the circuit before the projection.** Work over ℤ/2. Let g be any circuit polynomial representing a Boolean function and choose a power e=2ʲ>N. Append j squaring gates, obtaining gᵉ. On the Boolean cube its values equal those of g. For *every* polynomial substitution Mat over a characteristic-two field (after field extension if needed), let P=g(Mat). The new projected output is Pᵉ. If P=∑ₐcₐXᵃ then Pᵉ=∑ₐcₐᵉX^(e a) by Frobenius, so T_N(Pᵉ)=P(0)ᵉ, a constant. No choice of Mat can make that truncated polynomial take both 0 and 1 on short codes. The source already exhibits two fixed plain inputs of equal size, built by interchanging a quote program and a failing program, with values 1 and 0. In the contracting application H=16h with h≥17, so the length allowance v^(H−32) grows with v. Both fixed trees are short and plain at all sufficiently large scales. The abstract K.3 parameter also admits H=32, where length growth would fail. Thus an argument treating every Boolean-correct circuit unchanged, then choosing an affine projection and applying the original truncated evaluator, cannot recover these required answers. This holds conditionally for *any* size of the starting circuit, without assuming small circuits for HC. It leaves open preprocessing the circuit, choosing a better representative, or inventing a different evaluator. [Two universal values](https://github.com/anthropics/formal-math/blob/11b6c7e3c927df2658f513b6b68ea7f8929c62c5/vp-vnp/Paper/Circuit.lean#L39-L61)

## What the formal checking configuration covers

`Solution.lean` imports `Statement` and `Paper.Approximate` and supplies the exact and approximate bounds, the class separation and closure statement, and the real-permanent specialization. `comparator.json` requests these five named declarations, allows `propext`, `Quot.sound`, and `Classical.choice`, and enables the independent nanoda kernel. The challenge file deliberately places `sorry` in its five target statements. It is not imported by the solution. These are properties of the inspected source and configuration. A fresh reproduction of either checker is a separate claim. The repository identifies the proof as AI-produced, says that no human mathematician has checked it, and explicitly excludes the Boolean P versus NP conclusion. ### Independent replay of companion declarations

The companion's `audit_axioms.py` discovers the named public theorem declarations in the flat source modules, imports the compiled modules and runs `#print axioms` on each. It rejects missing or duplicate results, other Lean diagnostics, and any axiom outside the upstream allowlist. Its optional independent check exports those roots and their transitive proof dependencies with lean4export, then checks the export with nanoda in strict allowlist mode. The two checks provide an axiom audit and independent type checking for these declarations. Matching the theorem statements to the intended mathematics remains a human-facing inspection. The upstream CI separately compares its own five solution statements to its challenge file under Landlock. [Original CI script, lines 101–129](https://github.com/anthropics/formal-math/blob/11b6c7e3c927df2658f513b6b68ea7f8929c62c5/.github/scripts/comparator-check.sh#L101-L129)

For independent replay, build lean4export at `15f6055e299ad5b89345e533cc2192f4cc00f659` (tag v4.33.0) with Lean v4.33.1. This is the stable patch fallback used in the upstream CI script. This session used nanoda_bin 0.4.17 from the separately provisioned Lean v4.36.0 distribution. It consumed the v4.33.1 export; the binary that exports .olean files must match the compiled modules' Lean version. ```sh
python3 audit_axioms.py . --lean4export /path/to/lean4export --nanoda /path/to/nanoda_bin
