# Zero tours versus one tour suffices for the Boolean size question

Let $H_n$ decide whether a loopless directed graph on $n$ labelled vertices has a Hamiltonian cycle. Write $m=n(n-1)$ for its input length. The **unique-tour promise** requires a circuit to reject every graph with zero tours and accept every graph with exactly one tour. Its answers on graphs with two or more tours may depend arbitrarily on the graph. A tour is counted once by starting at vertex zero and following its directed arcs.

**Nonuniform equivalence.** General directed Hamiltonicity has polynomial-size Boolean circuits if and only if this promise has polynomial-size Boolean circuits. For the reverse implication it suffices even to solve the promise on planar directed graphs of maximum total degree three. This is an application of classical witness isolation and a parsimonious reduction. It identifies a sufficient target for a Boolean lower bound. The positive-surplus polynomial bounds in this project do not establish that lower bound. [Valiant and Vazirani, Theorem 1.1](https://ics.uci.edu/~vazirani/ValVaz.pdf) · [Bosboom et al., Theorem 3.1](https://erikdemaine.org/papers/LessThanEdgeMatching_JIP/paper.pdf#page=6)

## An isolation reduction with polynomial overhead

For a graph $G$, let $W_G$ be the set of its tours, represented by distinct $m$-bit arc incidence vectors. A Boolean verifier checks that the selected arcs belong to $G$, each vertex has exactly one selected predecessor and successor, and following successors from zero visits all vertices. Thus each tour has exactly one accepting input to this verifier.

Choose $m+1$ independent uniform affine linear equations over $\mathbb F_2$ on the $m$ witness bits. One trial tests **all** prefixes of lengths $k=1,\ldots,m+1$. For distinct witnesses the events of satisfying a fixed prefix are pairwise independent, since a uniform affine row gives uniform independent answers at two distinct points. If $d=|W_G|>0$, set $k=\lceil\log_2 d\rceil+1$ for the analysis. Then $\mu=d/2^k\in(1/4,1/2]$. The probability that exactly one witness survives this prefix satisfies
$$
\Pr[\text{one survivor}]\ \ge\ d2^{-k}-d(d-1)2^{-2k}\ \ge\ \mu(1-\mu)\ \ge\ 3/16.
$$
Indeed, for each designated witness subtract from its survival probability the sum of its joint survival probabilities with each other witness. The events that a designated witness is the unique survivor are disjoint. Prefix lengths from the same trial can be dependent. No tour survives any prefix on a negative graph.

For each prefix build the Boolean verifier for an input in $W_G$ satisfying those equations. Convert it to a graph whose tours are in bijection with the verifier's accepting assignments. The size is polynomial in $m$, even with the full matrix of hash coefficients written out. One explicit conversion uses a positive exact-one-in-three constraint per gate condition with uniquely determined auxiliaries. Write $R(a,b,c)$ when exactly one of the three distinct variables is true.

- The clauses $R(z,t,u),R(z,t,v),R(u,v,w),R(z,u,v)$ have the unique solution $z=w=1$ and $t=u=v=0$. They supply distinct forced constants.
- Give each input or gate output $a$ a complement $\bar a$ via $R(a,\bar a,u)$. To encode $o=a\land b$, introduce four variables $q_{00},q_{01},q_{10},q_{11}$ and impose $R(q_{00},q_{01},a)$, $R(q_{10},q_{11},\bar a)$, $R(q_{01},q_{11},\bar b)$, and $R(q_{11},\bar o,u)$. The row sums select $a$, and the sum in column one equals $b$. Thus just $q_{ab}$ is true and $o=q_{11}$. A NOT output uses $R(a,o,u)$. Pin the final output to one using $R(o,u,v)$. Every accepting verifier input has one extension by induction over the gates. A constant signal can use a fresh wire pinned to its value by the same construction. Every declared variable occurs.

Theorem 3.1 of Bosboom et al. now gives a planar, degree-three directed graph with one cycle per satisfying assignment. Its proof establishes parsimony starting from positive exact-one-in-three formulas, including nonplanar inputs, and explains simplicity when every variable occurs. For general loopless graphs, a separate explicit construction and finite tests give the same bijection by replacing each paired occurrence with a three-vertex path. The ordinary many-one NP-completeness of directed Hamiltonicity alone would not justify preserving singleton witnesses. [Planar construction, §3.1 and footnotes 3–4](https://erikdemaine.org/papers/LessThanEdgeMatching_JIP/paper.pdf#page=6) · [Positive verifier encoding](unique_verifier_gates.py) · [Explicit directed graph construction](unique-tour-gadget.md)

OR the promise circuit answers for all prefixes. Every negative input produces only zero-tour graphs, so every answer is zero. On a positive input, one singleton prefix already forces acceptance, irrespective of every answer on a multiple-tour graph. Repeat with $r=4(m+1)$ independent matrices. The probability of any given positive graph being missed is at most $(13/16)^r<2^{-(m+1)}$. There are only $2^m$ graphs. The union bound supplies **one fixed list** of matrices working on every graph of this order. Hardwire this list. Each polynomial-time reduction can be unrolled into a polynomial-size Boolean circuit. If query graphs vary in order, multiplex the promise circuits for all the polynomially many possible orders. There are polynomially many queries, so the resulting circuit has polynomial size. The forward implication follows by using an unrestricted decider unchanged. A uniform polynomial-time promise solver would instead yield a one-sided randomized polynomial-time algorithm and hence $\mathrm{NP}=\mathrm{RP}$. The nonuniform proof asserts existence of good matrices at each length.

## What happens to the hard polynomial layers

Every total completion of this promise has the same degree-$n$ canonical component, over every field. Graphs with fewer than $n$ arcs have zero tours, and an accepted graph with exactly $n$ arcs consists of a tour. Boolean Möbius inversion therefore gives coefficient one on each tour monomial and zero on the other degree-$n$ monomials. In fact the promise determines the canonical prefix through $n+2$. Two distinct successor permutations that are both $n$-cycles must differ on at least three images. They cannot differ at just one image by bijectivity, or at two because transposing two images changes the sign. Their union contains at least $n+3$ arcs. Every graph with at most $n+2$ arcs is thus a promised input. [Canonical prefix identity](degree-prefix.md)

In characteristic two there is a particularly informative completion: output the parity of the number of tours. On Boolean inputs its **entire canonical polynomial** is
$$
\mathrm{hc}_n(X)=\sum_{T\text{ a tour}}\prod_{e\in T} X_e.
$$
The right side is already multilinear, and each contained tour contributes one. Consequently **every positive-surplus layer of this valid completion is zero**, including the range where the actual existence predicate has hard components. A proof for the whole promise can use the common degree-$n$ part, but it cannot require positive-surplus hardness of every completion. The parity completion could itself be difficult. Establishing a Boolean lower bound for just this one completion would leave the other choices open. When monotonicity is required, the only possible completion is existence itself: every positive graph contains a tour, and its tour by itself is a promised positive input. [Formal lower bounds for the actual existence predicate](orbit-padding.md) · [Finite parity and isolation checks](promise_isolation.py)

The dense greedy family gives a concrete boundary for the promise. On the directed cycle $0\to1\to\cdots\to n-1\to0$, add the single forward chord $0\to2$, with $n\ge3$. There is still just one tour, because using the chord skips vertex one and the only remaining entrance to one was from zero. The greedy rule rejects immediately because zero has two unvisited successors. Thus a polynomial-size test can agree on factorially many dense unique-tour intervals and still fail on a promised input only one edge away from a bare cycle. [Dense unique-tour intervals](unique-tour-windows.md)

The circuit-size question that remains is whether **every** Boolean circuit family correct on all zero-tour and single-tour graphs requires superpolynomial size. Equivalently, one can seek a formal lower bound for the tour polynomial modulo the Boolean identities and squarefree monomials containing two tours. Errors generated by the latter alone preserve the formal bound. [Exact quotient and proof](unique-promise-ideal.md)

## Verification

Lean proves the finite seed-fixing and amplification argument and instantiates the zero-versus-one promise with rooted directed cycles. It takes the isolation probability and correctness on negative queries as hypotheses. The hash analysis, solution-preserving graph construction and polynomial-size composition above are written proofs. The programs check the hash reduction, the unique extension of circuit assignments, and the directed graph gadget. On five composed instances they also enumerate the actual tours of the graph built from the verifier and recover exactly its accepting inputs.
